## Implementation Notes (2026-10-14)

- core `packages/core/src/platform/`
  - `password.ts`: scrypt with N=2^15, r=8, p=3 (one of OWASP's equivalent settings, 32 MiB per hash)
  - `accounts.ts`: `PlatformAccounts` (signUp, logIn, authenticate, logOut, logOutEverywhere)
  - `throttle.ts`: `FailureThrottle`, 10 failures per 15 minutes, keyed by IP and by email
- server `packages/cli/src/server.ts`
  - Principal is machine, user or anonymous. Each route sets `access: public | user | machine`; the default is machine, so existing routes keep their behavior.
  - Routes: `POST /auth/signup` (logs in right away), `POST /auth/login`, `POST /auth/logout`, `GET /me`
  - Turned on with `tacet serve --accounts` / `TACET_ACCOUNTS=true`. Behind Render, add `--trust-proxy` / `TACET_TRUST_PROXY=true`.
- Decided trade-off: a duplicate email at sign-up returns 409, which reveals that the email is registered. Hiding it would require email verification, so revisit in TASK-0010.
- Reviewer: `/security-review` is required (ADR-0002).
- Tests: `platform-accounts.test.ts` (7) and `server-accounts.test.ts` (6). All 224 tests pass, including PostgreSQL.
