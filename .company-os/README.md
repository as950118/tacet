# ApiLens Platform — Company OS

지식은 Git Markdown, 실행은 `runtime/` (선택)입니다.

## Quick Start

1. Read `company/vision.md` → `values.md` → `org-chart.md`
2. Read your `roles/<role>.md`
3. Follow `docs/agent-collaboration-rules.md`
4. Start a workflow under `workflows/`
5. (Optional) Configure `runtime/.env` and run agents/graphs
