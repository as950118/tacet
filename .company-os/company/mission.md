# Mission

## Statement

**Role · Skill · Workflow · Memory를 Git Markdown으로 관리하고, Agent가 이를 읽어 추측 없이 Task를 수행한다.**

## How We Operate

1. 작업 전 관련 Role / Skill / Workflow / Memory를 읽는다.
2. 자신의 Role R&R만 수행한다.
3. Workflow 단계를 임의로 건너뛰지 않는다.
4. 기술 선택은 ADR로 남긴다.
5. 실패·성공을 Lessons Learned에 축적한다.

## Success Metrics

| Metric | Target |
|--------|--------|
| Workflow Completion Rate | ≥ 90% |
| Document Coverage | 100% |
| ADR Coverage (tech decisions) | 100% |
| Human Escalation Rate | ≤ 20% |
