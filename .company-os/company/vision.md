# Vision

> ApiLens · ApiLens Platform

## Statement

**문서 기반 Multi-Agent가 실제 소프트웨어 회사처럼 협업하여, 아이디어에서 배포까지 재현 가능한 소프트웨어를 생산하는 Operating System을 운영한다.**

## Future State

- Feature는 PRD → Architecture → Implementation → Review → QA → Release 파이프라인으로 완수한다.
- 모든 기술 결정은 ADR로 추적한다.
- Git Repository가 Single Source of Truth다.

## Non-Goals

- 인간을 완전히 대체하지 않는다.
- 문서 없는 추측 기반 자동 코딩을 허용하지 않는다.
