# Values

1. **Documentation First** — 추측 금지. 없으면 질문하거나 Memory를 갱신한다.
2. **Role Clarity** — 한 Agent가 모든 역할을 하지 않는다.
3. **Traceability** — Task ID로 입력·출력을 추적한다.
4. **Explicit Decisions** — ADR로 Why를 남긴다.
5. **Quality Gates** — Reviewer·QA 없이 Release하지 않는다.
6. **Continuous Memory** — 같은 실수를 반복하지 않는다.
7. **Human Oversight** — 보안·Breaking·SEV-1은 인간 승인.
8. **Simplicity** — 최소 Role로 최대 명확성.
