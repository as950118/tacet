# Coding Principles

1. **Read Before Write** — Task, PRD, Architecture, ADR, Memory 확인
2. **Small Diffs** — PR은 하나의 intent
3. **Explicit Interfaces** — API Spec 우선, Breaking은 ADR
4. **Fail Loud** — 예외를 삼키지 않는다
5. **Test Pyramid** — Unit / Integration / 핵심 E2E
6. **Security by Default** — Secret을 Git에 넣지 않는다
7. **Observability** — 핵심 경로 로그·메트릭
8. **No Silent Redesign** — 패턴 변경은 ADR 후

## Definition of Done
